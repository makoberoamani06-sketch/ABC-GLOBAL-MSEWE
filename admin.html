Unaelekezwa kwa Admin

Ikiwa haujaelekezwa otomatiki, tafadhali bonyeza hapa kuingia kwenye ukurasa wa Admin (login).

Kwa muhtasari: Admin ya kweli ipo kwenye Flask backend (/admin). Ili fomu ya login ifanye kazi, hakikisha una-deploy app kwa server (Render/Heroku) na umeweka mazingira (SECRET_KEY, ADMIN_USER, ADMIN_PASS).
